# Lanterna Submersa

Jogo narrativo de exploração e puzzles, 100% front-end.

```bash
npm install
npm run dev
```

## Deploy na Vercel
Suba para o GitHub e importe em vercel.com (Add New → Project). O Vite é detectado automaticamente.

## Estrutura
- `src/store`: estado (Zustand) e validação do save (Zod)
- `src/phases`: dados e cenas de cada fase
- `src/game/theme.ts`: paleta
